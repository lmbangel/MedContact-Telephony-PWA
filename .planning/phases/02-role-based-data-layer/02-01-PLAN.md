Add manager/supervisor role queries using MySQL 8.0 recursive CTEs. These queries must return data for ALL subordinates (not just direct reports), handling multi-level hierarchies.

1. **GetSubordinatesByManager** - Return all users who report to the manager (direct and indirect)
```sql
-- name: GetSubordinatesByManager :many
WITH RECURSIVE subordinates AS (
    SELECT id, firstname, lastname, agent_id, company_id, role, reports_to
    FROM users
    WHERE reports_to = ? AND company_id = ? AND is_active = 1
    UNION ALL
    SELECT u.id, u.firstname, u.lastname, u.agent_id, u.company_id, u.role, u.reports_to
    FROM users u
    JOIN subordinates s ON u.reports_to = s.id
    WHERE u.is_active = 1
)
SELECT * FROM subordinates
ORDER BY firstname ASC, lastname ASC;
```

2. **GetTasksByManager** - Return all tasks assigned to the manager's subordinates
```sql
-- name: GetTasksByManager :many
WITH RECURSIVE subordinates AS (
    SELECT id FROM users
    WHERE reports_to = ? AND company_id = ? AND is_active = 1
    UNION ALL
    SELECT u.id FROM users u
    JOIN subordinates s ON u.reports_to = s.id
    WHERE u.is_active = 1
)
SELECT t.* FROM tasks t
WHERE t.assigned_to IN (SELECT id FROM subordinates)
ORDER BY t.created_at DESC;
```

3. **GetCallsByManager** - Return all calls handled by the manager's subordinates
